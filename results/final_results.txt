============================================================
FINAL INTERPRETATION
============================================================

The adaptive controller provides the most benefit when the
shared-memory access pattern changes across phases.

When one static mapping is already optimal for the complete
workload, the adaptive controller mainly avoids unnecessary
mapping changes and matches the best static result.

The lifetime-safe controller demonstrates that adaptive mapping
can still reduce conflict cost while restricting remapping to
safe data-lifetime boundaries.
